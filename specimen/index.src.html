一支笔
One pen

每个字形都不是“画”出来的轮廓，而是一条笔的中心线（骨架），再让一个椭圆笔尖沿着它走一遍。轮廓是笔尖扫过的包络，最后拟合成 TrueType 的二次曲线。

椭圆笔尖

笔尖是一个横向略宽的椭圆（常规体 78 × 67 单位），所以竖画比横画稍粗，转角自然变圆。整套字只有这一支笔，粗细轴就是换一支更粗或更细的笔。

收笔与接笔

出锋的收笔会轻轻变细，像笔离开纸面；从竖画里长出来的弧（n、h、m 的肩）在起笔处收窄，免得交接处糊成一团。

汉字的骨架

汉字笔画来自 Make Me a Hanzi 的笔顺中线：去掉楷书起笔的小顿点，按原笔画轮廓重新量出起止点，再交给同一支笔书写。笔顺是真的，所以首页的描红也按笔顺来写。

粗体会让路

“鬱”“爨”这样笔画密的字在粗体里会挤成墨团。构建时按每个字的笔画总长估算密度，越密的字分到的额外粗细越少。

Get the font
      
日常用可变字体一个文件就够了；有的程序不认可变字体，就装静态版。

    

      

        

        

      

      
    
        
  1. Windows：双击 .ttf 点“安装”，或右键选“为所有用户安装”。
    2. 
        
  2. Windows Terminal：设置 → 配置文件 → 默认值 → 外观 → 字体，选 Clawd Mono。也可以写进 settings.json：
    
          
    "profiles": { "defaults": {
    "font": { "face": "Clawd Mono", "size": 12, "weight": "normal" }
} }

  3. VS Code（编辑器和内置终端）：
    
          
    "editor.fontFamily": "'Clawd Mono', monospace",
"terminal.integrated.fontFamily": "'Clawd Mono'",
"editor.fontVariations": true
